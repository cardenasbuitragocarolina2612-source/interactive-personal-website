# Interactive Personal Website

An interactive personal website developed to showcase my interests, personality, and creativity through a playful digital experience.

## About the project

This project combines personal presentation with interactive elements, including mini-games, trivia, memory challenges, and a book recommendation section.

## Technologies

- HTML5
- CSS3
- JavaScript
- Netlify

## Features

- Interactive welcome screen
- Mini-games
- Personal trivia
- Memory game
- Interactive activities
- Book recommendations

## Deployment

The website is deployed using Netlify.

**Live demo:** https://capable-pavlova-5ec9e5.netlify.app/

## Purpose

This project represents my practical experience in web development and my exploration of AI-assisted programming.
