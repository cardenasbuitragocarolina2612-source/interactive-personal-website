# ✨ Interactive Personal Website

An interactive personal website designed to showcase personality, interests, and creativity through a playful digital experience.

🌐 **[Live Demo](https://capable-pavlova-5ec9e5.netlify.app/)**

## 📌 About the Project

Interactive Personal Website is a personal web development project that combines creative design with interactive experiences.

The website allows visitors to explore different sections through mini-games, trivia, memory challenges, activities, and book recommendations.

This project was created as a practical way to develop web development skills and explore AI-assisted programming.

## 🚀 Features

- **Interactive Welcome Screen:** An engaging introduction to the website.
- **Mini-Games:** Small interactive experiences for visitors.
- **Personal Trivia:** Questions designed around personal interests.
- **Memory Game:** An interactive memory challenge.
- **Interactive Activities:** Different elements designed to encourage exploration.
- **Book Recommendations:** A section featuring books and reading interests.
